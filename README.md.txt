# 📄 PDF Merger using Python

A simple Python project that merges multiple PDF files into a single PDF using the PyPDF2 library.

---

## 🚀 Features
- Merge multiple PDF files into one
- Supports any number of PDFs
- Validates file existence before merging
- Beginner-friendly command-line tool

---

## 🛠 Tech Stack
- Python
- PyPDF2
