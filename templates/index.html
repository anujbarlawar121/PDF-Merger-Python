Why this feels better

From plain scripts to a proper application.

Your original Python logic is still the engine here. It is now wrapped in Flask routes, styled forms, file validation, helpful messages, and a richer classic visual theme.

Quick tips

  • Leave output names blank to use the suggested defaults.
  • Uploads are handled in temporary folders for cleaner runs.
  • The app supports PDFs plus common image formats.
